# TC4-1W+ — символ KiCad

Создан 2026-09-03 по запросу пользователя. Output change: отдельная библиотека для ручного добавления в проект. Внешний проект KiCad не изменён.

Файл: `GNSS_Transformers.kicad_sym`; символ: `TC4-1W+`. Формат KiCad 8 и новее.

Источник распиновки: https://www.minicircuits.com/pdfs/TC4-1W%2B.pdf

| Вывод | Назначение | Положение |
|---|---|---|
| 1 | Secondary dot | Слева сверху |
| 2 | Secondary center tap | Слева по центру |
| 3 | Secondary | Слева снизу |
| 6 | Primary dot | Справа сверху |
| 4 | Primary | Справа снизу |

Все выводы пассивные. Точки показывают начала обмоток. Отношение сопротивлений secondary/primary — 4:1, отношение витков — 2:1. Надпись 200:50 Ом показывает выбранное применение, а не сопротивление обмоток постоянному току. Вывод 5 в таблице производителя отсутствует и в символ не добавлен.

Для обсуждавшегося подключения ЦАП: 1 — IOUTA, 3 — IOUTB, 2 — GND, 4 — GND, 6 — IF-выход. Резистор 200 Ом между IOUTA и IOUTB является отдельным компонентом схемы.

Посадочное место: `GNSS_Transformers:TC4-1W_AT224-1A`, библиотека `GNSS_Transformers.pretty`. Назначено в символе 2026-09-03 по отдельному запросу пользователя.

Площадки прямоугольные, 0,762 × 1,651 мм. Шаг вдоль ряда 1,27 мм. Центры рядов y=±1,5875 мм; полный наружный размер площадок 4,826 мм. Вид сверху: верхний ряд 1–2–3 слева направо, нижний ряд 6–пусто–4. Площадки №5 нет. Номинальный корпус 3,81 × 3,81 мм; courtyard 5,0 × 5,5 мм учитывает габаритные допуски корпуса и запас. F.Fab показывает номинальный корпус; F.SilkS содержит маркер вывода 1. 3D-модель не включена.

Источник размеров: чертёж производителя AT224-1A Rev. AQ, https://www.minicircuits.com/case_style/AT224-1A.pdf . Нумерация и расположение дополнительно сопоставлены с исходником посадочного места в репозитории KiCad: https://gitlab.com/kicad/libraries/kicad-footprints/-/merge_requests/3151/diffs . Металлические площадки рассчитаны из дюймовых размеров H=.065, K=.030, D=.050, J=.190.

Для подключения footprint скопировать папку `GNSS_Transformers.pretty` целиком в свой проект и добавить её через «Настройки → Управление библиотеками посадочных мест → Библиотеки проекта». Имя библиотеки должно быть `GNSS_Transformers`. Обновить также файл символов; если символ уже размещён, обновить его из библиотеки либо назначить поле Footprint вручную.

Добавление: скопировать библиотеку в папку своего KiCad-проекта; в редакторе схем открыть «Настройки → Управление библиотеками символов → Библиотеки проекта» и добавить существующий файл. Затем выбрать `GNSS_Transformers:TC4-1W+`.
